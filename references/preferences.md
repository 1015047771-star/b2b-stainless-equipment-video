# 展示风格与声音参考

风格来自用户已认可的德正智能设备影片，可供不同品牌的 B 端不锈钢设备展示参考。新任务的明确要求优先，案例品牌与声音不自动套用到新项目。

## 品牌与视觉

- 品牌按当前项目设置，使用真实铭牌或用户提供标识，不擅造 logo 或型号。示例中的德正智能 / DEZSMART 仅属于历史案例。
- 写实、克制、有分量；低正侧面开场，完整外形与稳定运动，无装饰性圆台或蓝环。
- 银灰不锈钢具有反射层次，暗部可读，高光不过白。提亮是局部修正，不是通用 LUT。
- 白色/浅青色文字和少量短线，同一时刻一个主要信息组。字体按可用资源和手机尺寸预览决定，不要求复制某个 Windows 字体文件。

## 历史案例的已认可声音

- 当前项目已有认可声音时优先复用；新项目按品牌调性与用户要求选择。以下仅是德正智能案例记录。
- 服务记录：HeyGen；公开声音 Guoliang - Warm & Resonant，中文男声。
- voice ID：`1ddd191b2454466e9527983c9dcb4c14`。
- 历史返回引擎 `orca` 仅作为来源记录，调用前确认当前工具和声音兼容性，不强制填写旧字段。
- “原来的配音”表示声音身份延续；新文案要新音频，已有匹配文案则复用，不反复生成试听候选。
- 声音 ID 不是密钥；skill 不包含账号、API key 或音频下载 URL，不保证其他账号可用同一声音。

## 继续旧项目的相对线索

在用户当前项目中查找，不能依赖固定用户名或盘符：

- `outputs/edit/德正智能电动网版清洗机_精致标识配音版.mp4`：43 秒功能文字与配音案例。
- `outputs/edit/钢网清洗机_大角度开场_提亮纯画面版.mp4`：无字幕/无解说、保留配乐案例。
- `outputs/edit/premium_labels/`：样式、时间映射、单次语音来源和导出脚本。
- `outputs/edit/blender_full/`：模型、写实材质、机位及稳定修正工程。

这些不是安装 skill 的前提。旧项目缺失时依据新素材工作，不声称已读取缺失文件。案例脚本含固定路径和时间线，不能原样作为新机器的一键生成器。
