# 机型专属案例：只用于对应任务

## 电动网版清洗机

用户按实机照片修正过侧面深度、机身宽度、接缝及正方形观察窗。这些只适用于当时确认的型号，另一型号需要重新参考照片。

用户提供的对应机型功能：SMT 钢网锡膏残留清洗、丝印网版脱膜；自动清洗、自动漂洗、热风烘干；高压双面喷淋；水基清洗与过滤循环。它们不是所有清洗设备的通用功能。丝印脱膜不是清洗油墨的同义词。

用户认可用文字表达漂洗、烘干和过滤循环，不必补造内部仿真。清洁网孔是动画展示，不能推出无残留或不伤任何网版的保证。

案例为 43 秒、低机位连续 38° 转动，删除旧片 15–18 秒独立条件界面。这些时长、角度、焦距和时间点不是新片的默认参数。

## 选择性波峰焊

用户曾明确：由喷嘴上方涌出的锡接触板件，喷嘴本体不顶住电路板；表现连续焊接而非逐点点焊。板件、喷嘴大小和间距符合实机比例。

某个三排处理镜头使用等比放大的圆形喷嘴而非椭圆吸嘴。这是指定镜头方案，不表示所有设备都要三排同时处理。焊接、脱焊、清洗是不同工艺，先确认当前镜头目的。

## 已遇到的问题

- 金属板、立柱和窗框共面交叠导致闪纹：修几何接缝，不只增加采样或后期防抖。
- 运动门板超出局部渲染范围：合成区域要覆盖完整运动轨迹与边缘。
- Blender 原生 PNG 与后期 PNG 的像素比例/色彩标记不同，可能导致 H.264 头不匹配：核对后统一新片段，不盲目关闭验证。
- 绕机时反光会改变，起点、中段、终点都需检查；静态截图不能证明全程不抖。
- ASR 会在静音尾部编造内容，越过实际音频时长的文字不能直接成为字幕。
